Install on your server

Jellybot is a single container that talks to Jellyfin, stores a subtitle index on disk, and registers guild-scoped slash commands in Discord.

1. Discord application

Create a bot at the Discord Developer Portal with bot and applications.commands scopes.

Minimum permissions: Send Messages, Attach Files, Use Slash Commands.

2. Configure environment

cp .env.example .env
# Required:
# DISCORD_TOKEN, DISCORD_CLIENT_ID
# JELLYFIN_USERNAME, JELLYFIN_PASSWORD
# JELLYFIN_MOVIES_LIBRARY_ID, JELLYFIN_TV_LIBRARY_ID
# Optional web try-it API:
# WEB_API_ENABLED=1

3. Run with Docker

docker pull ghcr.io/introvrt-lounge/jellybot:latest
docker compose -f deploy/prod/docker-compose.yml up -d

Mount persistent data for the subtitle index:

volumes:
  - ./data:/var/lib/jellybot/data

4. Register commands & index subtitles

make register-commands
make index-subtitles

Re-run incremental indexing after new subtitle files land in Jellyfin.

5. Verify

curl -s http://127.0.0.1:8080/healthz | jq .
curl -s http://127.0.0.1:8080/api/v1/meta

In Discord: /quote autocomplete should return indexed matches after the index build completes.
